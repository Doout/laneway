# Security policy

Laneway is security-sensitive networking software. Please do not disclose a
suspected vulnerability in a public issue.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Doout/laneway/security/advisories/new).
Include the affected version, deployment mode, impact, and the smallest useful
reproduction. Reports will be acknowledged as soon as practical.

Security fixes target the latest release and the `main` branch. The protocol
security boundaries and current non-goals are documented in
[`spec/threat-model.md`](spec/threat-model.md).
